# frag-assets

Image assets for Fragment of Japan (https://fragment-of-japan.blogspot.com/).

Layout: img/<item-id>/<type>.<ext>  -  for example, img/battera/prepared.jpg
<type> matches the visualPrompts[].type field of the item record.

Files are kept in the format they were produced in. They are not converted,
because format conversion strips C2PA provenance metadata.

Some images here are produced with AI image models. The item record marks this
per image, and the article page carries the credit.
